# ランダム英数字10文字ジェネレーター

シンプルな 1 画面構成の Web アプリです。ページ表示時に **英数字10文字** を自動生成し、ボタンで再生成できます。

## 機能

- 初回表示時にランダム英数字10文字を生成
- 「再生成」ボタンで文字列を更新
- 「コピー」ボタンで生成結果をクリップボードへコピー

使用文字は次の 62 文字です。

- `A-Z`
- `a-z`
- `0-9`

## 起動方法

このリポジトリでは追加のビルドは不要です。`index.html` をブラウザで開くだけで動作します。

例: Python の簡易サーバーを使う場合

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` にアクセスしてください。

## 確認方法

1. 画面中央付近に 10 文字の英数字が表示されることを確認
2. 「再生成」ボタンを押し、表示文字列が更新されることを確認
3. 文字列が毎回 10 文字であることを確認
4. 「コピー」ボタン押下後、任意の入力欄に貼り付けできることを確認
